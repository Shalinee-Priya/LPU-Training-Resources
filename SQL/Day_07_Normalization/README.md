## Overview

Welcome to **Day 7** of the SQL learning series.

This module introduces **Database Normalization**, one of the most important concepts in relational database design. Students learn how to eliminate redundancy, identify anomalies, and transform an unnormalized database into **1NF, 2NF and 3NF**.

---

## Learning Objectives

After completing this module, you will be able to:

- Explain normalization
- Identify redundancy
- Detect update, insert and delete anomalies
- Convert UNF into 1NF, 2NF and 3NF
- Understand partial and transitive dependency
- Design maintainable relational databases

## Business Case Study

This module uses an **E-commerce OrderData** dataset stored in `03_SQL_Day7_Dataset.sql`.

The unnormalized table intentionally contains repeated customer, supplier, and product information to demonstrate:

- Data Redundancy
- Update Anomaly
- Insert Anomaly
- Delete Anomaly
- Transformation from **UNF → 1NF → 2NF → 3NF**

Students progressively redesign this single table into a clean relational database, making it the perfect bridge to **Day 8: SQL JOINS**.
