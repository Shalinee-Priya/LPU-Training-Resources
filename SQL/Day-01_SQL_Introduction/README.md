# SQL Day 1: Introduction to Databases & SQL

**Author:** Shalinee Priya  
**Role:** Data Analyst | SQL Trainer  
**Module:** B.Tech SQL Training

---

## Overview

Welcome to **Day 1** of the SQL learning series. This module introduces the fundamentals of relational databases, SQL syntax, and MySQL Workbench. By the end of this session, you'll create your first database, design a table, insert records, and execute basic SQL queries.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand SQL and RDBMS
- Differentiate File System vs Relational Database
- Explain databases, tables, rows, and columns
- Follow standard SQL syntax conventions
- Create and use a MySQL database
- Create tables and insert records
- Execute basic `SELECT` queries

---

## Topics Covered

- What is SQL?
- What is RDBMS?
- File System vs RDBMS
- Database & Table
- Rows, Columns & Primary Key
- Advantages of SQL
- SQL Syntax Rules
- MySQL Workbench
- Creating Your First Database & Table
- Practice Session
