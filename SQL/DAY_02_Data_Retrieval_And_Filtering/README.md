## Overview

Welcome to **Day 2** of the SQL learning series.

This module focuses on **retrieving, filtering, and organizing data** from relational databases. Building upon Day 1, students learn how to write meaningful SQL queries using `SELECT`, `WHERE`, logical operators, sorting, and limiting results—the foundation of most SQL interview questions.

---

## Learning Objectives

After completing this module, you will be able to:

- Retrieve data using `SELECT`
- Display specific columns instead of `SELECT *`
- Remove duplicate values using `DISTINCT`
- Rename output columns with `AS`
- Create calculated columns using SQL expressions
- Filter records using `WHERE`
- Apply `AND`, `OR`, and `NOT`
- Use `BETWEEN`, `IN`, `LIKE`, and `IS NULL`
- Sort data using `ORDER BY`
- Retrieve **Top N** records using `LIMIT`

## Interview Focus

- `SELECT` for data retrieval
- `WHERE` for filtering
