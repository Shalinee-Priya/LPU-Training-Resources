## Overview

Welcome to **Day 6** of the SQL learning series.

This module introduces the **Entity-Relationship (ER) Model**, the foundation of relational database design. Before writing SQL queries, developers first identify entities, attributes, relationships, and cardinality to create a scalable database blueprint.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand database design
- Explain the ER Model
- Identify entities and attributes
- Define relationships between entities
- Interpret cardinality (1:1, 1:M, M:N)
- Convert an ER diagram into relational tables
- Design interview-ready database schemas

## Why This Module Matters

A good database is designed **before** it is implemented.

This module teaches how business requirements become relational tables through the ER Model.

Example:

- Student
- Department
- Course
- Instructor
- Enrollment

These entities later become SQL tables connected through Foreign Keys.
