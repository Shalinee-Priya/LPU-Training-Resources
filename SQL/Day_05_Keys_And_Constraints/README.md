## Overview

Welcome to **Day 5** of the SQL learning series.

This module introduces **Keys & Constraints**, the foundation of database design. Instead of focusing on writing queries, students learn how SQL ensures **data integrity**, prevents invalid records, and creates reliable relationships between tables.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand data integrity
- Create Primary Keys and Foreign Keys
- Use UNIQUE, NOT NULL, DEFAULT, and AUTO_INCREMENT
- Identify constraint violations
- Design reliable relational tables
- Solve interview-oriented database design questions

## Why This Module Matters

Before learning JOINS, every SQL developer must understand how tables are connected and how databases prevent incorrect data.

Examples include:

- Duplicate Student IDs
- Missing Employee Names
- Invalid Placement Records
- Repeated Email Addresses

Constraints solve these problems automatically.
