## Module Overview

Welcome to **Day 9** of the SQL learning series.

After learning **SQL JOINS**, students already know how to combine multiple related tables. This module introduces **Subqueries (Nested Queries)**, where one SQL query becomes the input for another query to solve intelligent filtering and comparison problems.

The entire module **reuses the same E-commerce database from Day 8**, reinforcing continuity while teaching a new SQL technique.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand the purpose of Subqueries
- Differentiate Inner Query and Outer Query
- Write Single Row and Multi Row Subqueries
- Use `IN`, `NOT IN`, `ANY`, `ALL` and `EXISTS`
- Compare JOINs and Subqueries
- Solve interview-oriented business problems using nested queries
